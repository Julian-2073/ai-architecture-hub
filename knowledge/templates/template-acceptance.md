## 录入、编辑与保存任务（适用时）

按实际风险选用，普通展示页不必机械执行全部项目。

| 场景 | 应核对的结果 | 实际观察与证据 |
|---|---|---|
| 正常保存并重新查询 | 字段、对象ID和版本符合已提交结果，列表/详情一致 | |
| 字段不合法或服务端拒绝 | 错误可定位，未误报已保存，待编辑内容按产品规则保留 | |
| 网络失败与重复点击 | 不重复创建或静默覆盖，恢复/重试和结果回读有据可查 | |
| 多人修改同一对象 | 冲突按既定规则处理，不把本地缓存值当最终事实 | |
| 切换账号/企业/筛选后旧响应返回 | 不把旧范围数据写回当前界面或草稿 | |
| 翻页排序与行编辑 | 稳定业务行ID，选择/修改不落到另一条记录 | |

字段校验通过、提交回调被调用、网络成功状态、缓存更新与数据库结果分别核对；只在相关层实际可观察时记录通过。
