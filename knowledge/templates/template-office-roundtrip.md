# Office / PDF 导入导出与保真边界

适用于把表格、Word、PPT、PDF 接入软件或批量生成交付物。先区分“提取数据、新建文件、修改原件、渲染预览、无损往返”，它们不是同一能力。

## 任务与原件

- 输入/输出格式及实际来源：
- 新建还是改现有原件？哪些内容必须保留？
- 数据读取、公式计算、样式、图表、宏、修订、域、动画分别是否在范围内？
- 目标应用：Excel / LibreOffice / WPS / 浏览器 / PDF 阅读器等具体版本。
- 原件绝对路径、备份、修改范围和回退方式：

| 对象 | 原始语义 | 必须保留的属性 | 候选工具实际支持证据 | 验证办法 |
|---|---|---|---|---|
| 单元格、空白与0 | | | | |
| 日期、时区与金额 | | | | |
| 公式与缓存值 | | | | |
| 表格、图表和图片 | | | | |
| 字体、分页和母版 | | | | |
| 宏、批注、修订等 | | | | |

## 技术分支

只提取数据→优先数据格式库；生成新文件→生成库；保留复杂原件→先验证原生编辑或受支持的原件操作路线；PDF文字→先判断原生文本还是扫描图像；需要计算公式→寻找明确计算引擎，不能把写入公式当作计算。

## 验收

关键数据与计算对照、导出后重新读取、目标Office打开、正式渲染与视觉检查分别记录。未覆盖对象明确列出，不能以“文件打开成功”作整体保真结论。
