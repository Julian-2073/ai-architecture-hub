# 在地图上查看地点轨迹和区域

ID：`scenario-geo-map`。这是一条任务发现与交接规则，不是已完成的软件或技术采用决定。

## 业务描述入口

地图 / 地理 / 区域 / 地点 / 坐标；轨迹 / 标记 / 分布 / 物流 / 门店 / 查看 / 展示。

## 先判断什么

先检查当前项目相关实现、依赖和平台能力；现有方案够用时复用，不因匹配到场景就新增框架。

先复用当前栈；对同职责候选作比较，对跨职责组件明确接口。列表不是全部要安装的技术栈。

- 目标地区与坐标来源是什么？
- 地图数据、瓦片和地理编码由谁提供？

## 技术职责与候选

- [MapLibre GL JS](../technologies/tech-maplibre.md)：交互式矢量地图与地图样式。
- [deck.gl](../technologies/tech-deckgl.md)：以图层显示大量地理或空间数据。

## 模块与数据流

地理数据 → 坐标校验 → 底图与图层 → 筛选交互。

## 实现后应观察

- 点位和坐标正确
- 目标地区访问及数据许可明确
