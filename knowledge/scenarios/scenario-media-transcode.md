# 转换剪切音视频文件

ID：`scenario-media-transcode`。这是一条任务发现与交接规则，不是已完成的软件或技术采用决定。

## 业务描述入口

视频 / 音频 / 录音 / 媒体；转码 / 格式转换 / 剪切 / 合并 / 压缩 / 字幕 / 提取。

## 先判断什么

先检查当前项目相关实现、依赖和平台能力；现有方案够用时复用，不因匹配到场景就新增框架。

先复用当前栈；对同职责候选作比较，对跨职责组件明确接口。列表不是全部要安装的技术栈。

- 目标播放器与编码是什么？
- 是否涉及受限编解码器与授权素材？

## 技术职责与候选

- [FFmpeg](../technologies/tech-ffmpeg.md)：转码、封装、滤镜与流媒体处理。

## 模块与数据流

媒体探测 → 处理参数 → 转码与封装 → 播放检查。

## 实现后应观察

- 音画同步和时长正确
- 目标设备可播放
