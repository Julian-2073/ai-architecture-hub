## 具体边界

卡片、场景和模板是知识与建议，上述测试不证明 180 种技术全部可用，不验证其中维护/许可等时效断言，也不构成任何业务项目集成或运行验收。

测试中的项目、历史结果和失败经验夹具仅用于校验检索与证据规则，不代表本库已完成真实项目。

当前只验证 Skill 文件结构与安装行为，没有对本社区包重新执行跨聊天实际触发；宿主加载和使用效果需要新聊天实测。CI 配置使用 GitHub 官方 Actions 固定提交，Python 3.10/3.12/3.13 的远端结果以 Actions 页面为准，本地通过不等于远端 CI 已通过。
